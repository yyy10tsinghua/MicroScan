# MicroScan 🔬

**显微扫描仪 - Microscope Image Stitching Scanner**

MicroScan 是一个开源的显微镜图像拼接工具，可搭配数码显微镜使用，通过移动被观察样本（如纸币、电路板、生物切片等），自动将拍摄的图像拼接成高分辨率的全景图。

## ✨ 功能特性

### 📷 实时扫描模式 (Live Scan)
- 连接 USB 数码显微镜，实时预览
- **自动图像拼接**：当移动样本时，自动检测重叠区域并拼接
- **分辨率自适应扩展**：画布随扫描范围自动扩展，无尺寸限制
- **重叠引导系统**：
  - 颜色指示（绿色=良好重叠，黄色=需调整，红色=追踪丢失）
  - 方向箭头提示下一步移动方向
  - 实时重叠率百分比显示
- 支持多种分辨率：640×480, 800×600, 1280×720, 1920×1080
- 可缩放和平移查看拼接结果

### 🎬 视频转图片模式 (Video Import)
- 导入显微镜拍摄的视频文件
- 自动识别帧间重叠区域
- 智能跳帧处理，降低冗余
- 后台线程处理，不阻塞界面
- 支持格式：MP4, AVI, MOV, MKV, WMV

### 🛠 技术特点
- **特征匹配 + 相位相关**双重定位算法
- **ORB 特征检测**（免费，高效）
- **RANSAC** 鲁棒匹配
- **距离加权融合**（Feather Blending）消除拼接缝隙
- 动态画布扩展，内存高效
- 深色主题 GUI

## 📋 系统要求

- Python 3.8+
- USB 数码显微镜（用于实时扫描模式）
- Windows / macOS / Linux

## 🚀 快速开始

### 安装

```bash
# 克隆仓库
git clone https://github.com/yyy10tsinghua/MicroScan.git
cd MicroScan

# 安装依赖
pip install -r requirements.txt
```

### 运行

```bash
python run.py
```

### 实时扫描步骤

1. 连接 USB 显微镜
2. 在 Camera 下拉框选择设备 → 点击 **Connect**
3. 调整分辨率（建议 1280×720）
4. 点击 **▶ Start Scan**
5. 缓慢、平稳地移动样本
6. 观察重叠率指示器：
   - 🟢 **20%~50%**：最佳重叠，自动拼接
   - 🟡 **<15% 或 >70%**：需要调整移动速度
   - 🔴 追踪丢失：缓慢移回
7. 扫描完成后点击 **⏹ Stop Scan**
8. 点击 **💾 Save Panorama** 保存结果

### 视频处理步骤

1. 切换到 **🎬 Video Import** 标签
2. 点击 **📂 Load Video** 选择视频文件
3. 设置跳帧数（建议 2-5）
4. 点击 **▶ Process Video**
5. 等待处理完成
6. 点击 **💾 Save Panorama** 保存

## 🔧 算法说明

### 图像配准
1. **ORB 特征检测**：提取图像关键点和描述子
2. **BF 匹配 + 比率测试**：筛选可靠的匹配对
3. **RANSAC 单应性估计**：鲁棒地计算变换矩阵
4. **相位相关备选**：当特征匹配失败时，使用频域相位相关

### 画布管理
- 首帧初始化画布（带预留边距）
- 新图像通过累计平移量定位
- 画布不足时自动扩展（带额外填充）
- 仅裁剪有内容区域输出

### 图像融合
- **距离加权融合**：像素的权重与其到图像边缘的距离成正比
- 重叠区域进行加权平均，消除明显接缝
